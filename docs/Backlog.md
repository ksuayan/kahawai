## Headphone correction: AutoEq import

Goal: let a user load a headphone correction profile (the AutoEq `ParametricEQ.txt` format, `Preamp: -6.2 dB` then `Filter N: ON PK|LSC|HSC Fc … Hz Gain … dB Q …` lines) into the EQ. **Import only: Kahawai ships no profile data.** AutoEq's code is MIT, but its README states no licence or permission terms for the measurements (oratory1990, Crinacle, Innerfidelity, Rtings) the profiles are computed from, so bundling profiles is a separate, unresolved question (last story). The stories below are ordered by dependency. Gap analysis: the EQ already has every filter type AutoEq uses; what is missing is the band count, a preamp, a shelf-Q conversion and the import itself. Confirm the file format against a real AutoEq download before building the parser (this list is from memory).

| Item | Why / notes | Details | Status |
|---|---|---|---|
| **Raise the 8-band EQ cap** | *As a user with an AutoEq profile, I want all of its filters to load.* Typical profiles have 10 filters, more than `MAX_EQ_BANDS = 8` ([dsp.rs](../crates/kahawai-player-core/src/dsp.rs)), so they would not fit. Raise the cap (10 to 12), then check that the UI in [EqEditor.vue](../player/ui/src/components/EqEditor.vue) still lays out and that DSP cost is acceptable (biquads are cheap, so this is mostly a UI and test task). Prerequisite for the import. | Size: **S**<br>Phase: **v2**<br>Priority: **P2** | **Not started** |
| **EQ preamp (global gain)** | *As a user, I want a boosted profile not to clip.* AutoEq profiles start with a negative `Preamp` that offsets their boosts. The EQ has no pre-gain (see "Reuse the level meter for the EQ" below); the look-ahead limiter would duck the peaks, which is not the same as attenuating first. Add an EQ preamp (dB) applied before the filters or through the existing loudness gain ramp, persisted with the bands and part of a preset, with the same click-free ramp as live edits. Also lets a hand-made EQ use it. | Size: **M**<br>Phase: **v2**<br>Priority: **P2** | **Not started** |
| **Parse an AutoEq `ParametricEQ.txt`** | *As a user, I want to import a profile file I downloaded.* A pure parser in `kahawai-player-core` (no I/O, hermetic cargo tests) from text to `Vec<EqBand>` plus the preamp: `PK` to Peaking, `LSC`/`HSC` to shelves (also `LP`/`HP` if present), skipping `OFF` lines, tolerating extra whitespace and unknown lines with a warning list. **Shelf Q is not the same as ours:** AutoEq uses the standard RBJ Q (usually 0.7); our shelves take the slope S (clamped 0.1 to 3.0), so convert with S = 1 / ((1/Q² − 2)/(A + 1/A) + 1), where A = 10^(gain/40). ## DSP effects (research first)

Both items below need the same groundwork, so plan them together:

- **A stage seam.** Extract the `DspStage` trait sketched in v1/EQ.md section 6, so the EQ, tape and tube stages are interchangeable and orderable in the PCM chain (decode, resample, [stages], loudness, volume).
- **Oversampling.** Saturation creates harmonics above the original bandwidth; without 2x to 8x oversampling around the non-linear part they alias back as harsh, inharmonic distortion. This is the main CPU cost, and the playback thread must still keep ahead of the device (see the 200 ms ring buffer in [cpal_sink.rs](../crates/kahawai-player-audio/src/cpal_sink.rs)).
- **Same path rules as the EQ.** PCM shared path only. DoP and bit-perfect playback bypass these effects, and the UI dims them with the same "not supported for this stream type" message.
- **Level discipline.** Non-linear stages care about input level. Decide where in the chain they sit relative to loudness normalization and volume (level in, level out, and a drive control), and add a gain-matched A/B so "better" is not just "louder".
- **Live edits without clicks.** Reuse the EQ's fade approach for parameter changes and on/off.
- **Licensing and naming.** Prefer our own implementations from published papers and measurements. Check the licence before borrowing from open-source emulations (some are GPL). Use "inspired by" wording for classic gear names; the names are other companies' trademarks.
